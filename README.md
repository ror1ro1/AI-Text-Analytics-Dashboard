# AI Text Analytics Dashboard

An interactive, production-ready web application built with Python and Streamlit. The platform enables users to ingest unstructured text data or system logs and trigger specialized AI intelligence workflows via a graphical user interface.

## Features
- **Interactive UI Components**: Leveraging Streamlit for dynamic parameter adjustments (task selection, temperature controls).
- **Multi-Task Orchestration**: Built-in pipelines for autonomous text summarization, deterministic action item extraction, technical sentiment routing, and localization.
- **Enterprise Core**: Seamless integration with the modern `google-genai` SDK for low-latency inference.

## Tech Stack
- **Frontend / UI**: Streamlit Framework
- **Language**: Python 3
- **AI Core**: Google Gemini 2.5 Flash API
